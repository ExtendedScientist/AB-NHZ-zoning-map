# Boston Zoning Precedent Map

Public hosting repository for the Boston Zoning Precedent Map.

**Live map:** https://extendedscientist.github.io/AB-NHZ-zoning-map/

The deployed map is an analytical scenario applying Boston Neighborhood Housing zoning precedent to Allston-Brighton. It is not an official City of Boston zoning proposal or prediction of future City action.

The development source and history are intentionally maintained separately. This repository contains only generic hosting/bootstrap files; approved map releases are supplied as privacy-audited static deployment artifacts.
